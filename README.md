# Career Companion

A personal career management system that helps users track learning progress, skills, resources, job applications, interview rounds, and long-term career goals.

## Status

🚧 Under Development

## Core Workflow

Career Companion connects career planning and progress through related entities:

Primary Goals
→ Secondary Goals
→ Skills
→ Resources

Job Applications and Interview Rounds can also be connected to career goals.

## Current Features

- User Authentication
- User Profile Management
- Primary and Secondary Goal Management
- Goal Progress Tracking
- Skills Management
- Resource Management
- Job Application Tracking
- Interview Round Tracking
- Dashboard Analytics
- Career Journey Overview
- Search, Filtering, and Sorting
- REST API
- MongoDB Database
- JWT Authentication

## Future Direction

Career Companion is being developed toward a connected career planning system where Primary Goals can be broken down into Secondary Goals, Skills, and Resources.

The system will preserve relationships between these entities so that progress can be understood across the career journey rather than as isolated activities.

## What Career Companion Will Not Do

- Teach programming
- Host courses or videos
- Replace learning platforms
- Depend on AI
- Become a social media platform
